# Tame Every Mob Wiki – GitHub Pages

This folder is ready for GitHub Pages.

## Publish for free

1. Create a new **public** GitHub repository, for example `tame-every-mob-wiki`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the public wiki URL.

## Current content

- Searchable taming list
- Category filters
- English/German language toggle
- Boss rules and relative taming chance multipliers
- FAQ for Enderman, Ender Dragon and Red Taming Guide issues
- Data verified against the current Fabric 1.21.1 source tree (1.4.1 development)
